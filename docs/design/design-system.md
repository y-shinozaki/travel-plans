# デザインシステム — Aman (aman.com) 由来の仕様

> ハードコードされた 16 進数値をコードに書かないでください。色は必ず `assets/css/tokens.css` の CSS 変数を参照してください。

---

## 1. 出典

[aman.com](https://www.aman.com/) の computed style を 2026-08-09 に実測。色・タイプスケール・余白グリッドの数値はすべてこの実測に基づく。旧版（代官山 蔦屋書店を出典とする版）の内容は本ドキュメントから完全に置き換えた。

検証済みの参照実装は `docs/design/aman-mock.html`（約 4,300 行）。本ドキュメントの数値の大半はこのモックの `<style>` ブロック（17〜81 行目）から抽出したトークン値と一致する。

---

## 2. Visual Theme

- **無彩色基調**: ブランドカラーと呼べる有彩色を持たない。彩度の低いサンド・アイボリー系の背景と、黒に近いインクの文字色のみで構成される
- **写真主役**: レイアウトは大判の写真を中心に組まれ、テキストは補助的な余白の中に控えめに置かれる
- **極端な余白**: セクション間の余白が本文サイズの何倍にもなる。「情報を詰める」代官山 蔦屋書店とは対照的に、「間を持たせる」ことそのものが装飾になっている
- **行間の一貫性**: 本文・小見出しを問わず `line-height: 1.45` がほぼ全域に適用されている（実測）
- **大文字化はラベルとコントロール類のみ**: `text-transform: uppercase` はミクロラベルやボタン・チップなどのコントロール類にのみ使われ、見出しや本文には使われない（詳細な適用範囲と実例は §5 Typography 参照）

## 4. Category Colors

### 考え方

各カテゴリは `--c-X`（アクセント）／`--c-X-bg`（ティント地）／`--c-X-tx`（文字）の3値セットを持つ。

初期の設計案では低彩度の濃色をカレンダーブロックにベタ塗りしていた。しかしカレンダー上でグリッド状に隣接して並ぶと、色同士が混色して見えて濁り、白文字を重ねても判読しづらかった。そこで方針を変更した。

- **面**はティント地（`-bg`）で塗る — 淡いので隣接しても濁らない
- **識別**はブロック左端の 3px 縦アクセントバーとアイコンに任せる — アクセント色はティント地より十分濃いので、細い線でも視認できる
- **文字**はティント地に対して濃い同系色（`-tx`）を使う — 白文字よりコントラストが高く取れる

### パレット値（派生 — aman.com からの実測ではなく本プロジェクトで設計した値）

`assets/css/tokens.css` からの転記。

| カテゴリ | アクセント `--c-X` | ティント地 `--c-X-bg` | 文字 `--c-X-tx` |
|---|---|---|---|
| 移動 (move) | `#3f5c50` | `#d6e8db` | `#22352d` |
| 観光 (sight) | `#7e5318` | `#f6e7c0` | `#4a3212` |
| 食事 (food) | `#a54a2c` | `#f9e2d7` | `#58281a` |
| 宿泊 (hotel) | `#2f566f` | `#d8e6f4` | `#1c3446` |
| 買物 (shop) | `#6a4c78` | `#ede2f2` | `#38263f` |

### 検証値（`tests/tokens.test.js` で数値検証）

| 検証項目 | しきい値 | 実測範囲（5カテゴリ） |
|---|---|---|
| 文字（`-tx`）とティント地（`-bg`）のコントラスト | 7.0 以上 | 9.7〜11.1 |
| アクセント（`--c-X`）とティント地（`-bg`）のコントラスト | 4.5 以上 | 4.7〜6.2 |
| アクセントに白文字（`--sand-lt`）を載せた際のコントラスト | 4.5 以上 | 5.5〜7.5 |
| ティント地どうしの色距離（RGB ユークリッド距離） | 20 以上 | 21 以上（最小は hotel/shop 間） |
| ティント地とカレンダー下地（`--sand-lt`）の色距離 | 25 以上 | 28 以上（最小は shop） |

これらの数値はパレットを編集するたびにテストが再計算する。将来の配色変更が可読性を損なった場合はテストが失敗して知らせる。しきい値を下げて通すことはしない。

## 5. Typography

### フォント代替表

Aman の実際の書体（見出し: Lyon、本文: Whitney）はいずれも有償のため、無料の近似フォントに置き換えている。

| 役割 | Aman 実書体（有償） | 本プロジェクトの代替（無料） |
|---|---|---|
| 見出し（serif） | Lyon | `"Newsreader", "Noto Serif JP", "Times New Roman", serif` |
| 本文（sans） | Whitney | `"Inter", "Noto Sans JP", sans-serif` |

### タイプスケール（実測）

aman.com の computed style から採取したサイズ・字間の一部:

| 用途 | font-size | letter-spacing |
|---|---|---|
| 小ラベル（ナビ・カテゴリラベル等） | 10.1px | 2px |
| 補助テキスト | 13px | — |
| 本文 | 14px | 0.8px |
| 小見出し（serif） | 19.6px | 0.98px |
| 大見出し（serif） | 31.08px | 0.5px |

### 大文字化（uppercase）の適用範囲

### 行間

`line-height: 1.45` を本文・小見出しの両方で一貫して使用する（実測）。代官山 蔦屋書店版の `line-height: normal`（詰めた行間）とは対照的に、Aman は余白と同じくらい行間そのものを意匠として扱っている。

## 7. Radius

Aman のサイトは実測で**すべての要素が `border-radius: 0px`**（直角主義）。本プロジェクトはこれをそのまま踏襲せず、カレンダーやカードに柔らかさを持たせるために**意図的に逸脱**し、5段階の角丸を導入した。これは実測値ではなく、このプロジェクトの決定である。

| トークン | 値 | 用途 |
|---|---|---|
| `--r-xs` | 5px | イベントブロック、終日ピル、チェックボックス |
| `--r-sm` | 8px | サムネイル、入力欄 |
| `--r-md` | 12px | 中サイズの面 |
| `--r-lg` | 18px | カレンダー、地図、カード、パネル、テーブル |
| `--r-pill` | 999px | ボタン、チップ、バッジ、地図ピン |

## 8. Motion

演出の対象ごとにイージングと時間を使い分ける。いずれもこのプロジェクトの決定であり、aman.com からの実測値ではない。

| トークン | 値 | 想定用途 |
|---|---|---|
| `--e-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 要素の出現・展開など、勢いよく開始して滑らかに止まる動き |
| `--e-io` | `cubic-bezier(0.65, 0, 0.35, 1)` | パネルの開閉など、対称的な加減速が必要な動き |
| `--t-fast` | 0.32s | ホバー、トグル、フィルター切り替えなど短い反応 |
| `--t-mid` | 0.55s | カード出現、詳細パネルのスライドインなど中程度の演出 |
| `--t-slow` | 0.9s | ヒーローのフェードアップなど、じっくり見せたい演出 |

`prefers-reduced-motion: reduce` が指定された環境では、これらのトランジション・アニメーションを無効化するか、`--t-fast` 相当まで短縮する。動きそのものに情報を持たせず装飾に留めているため、無効化しても機能は失われない。

## 9. Icons

- アイコンはすべて**インライン SVG**（アイコンフォントや外部からの動的読み込みではなく、自前のスプライトを `<use>` 等で参照する想定）
- 線幅は **1.0〜1.4px** の細い線を基本とする。Aman の無彩色・低コントラストなトーンに合わせ、太い塗りつぶしアイコンは使わない
- 色は `stroke="currentColor"` / `fill="currentColor"` で親要素のテキスト色に追従させる。カテゴリごとの色分けはアイコン自体の色を変えるのではなく、アイコンを置く親要素の `color` をカテゴリのアクセント色（`--c-X`）に設定することで実現する
